# Setup

1. Create a public GitHub repository whose name exactly matches your GitHub username.
2. Copy `README.md` and the entire `assets` folder into the repository root.
3. In `README.md`, replace the placeholder email address with your real email.
4. Confirm your LinkedIn slug and GitHub username; update both links if needed.
5. Commit and push the files. GitHub will display the README on your profile.

The design uses local SVG assets and remote Devicon technology icons. Keep the `assets` folder beside `README.md` so the header and navigation cards render correctly.
